# Congratulations

A Jetpack Compose greeting card — a small, complete example of composing text and layering it on a themed background.

## Features

- Single-screen Compose UI with a custom Material 3 theme
- Custom typography and color definitions
- `@Preview` support for design-time iteration

## Tech stack

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **SDK:** min 24, target 35
- **Package:** `com.example.congratulations`

<sub>6 source files · 168 lines of code</sub>

## Getting started

```bash
git clone https://github.com/rajabbov/Congratulations.git
```

Open the folder in Android Studio, let Gradle sync, and run the `app` configuration on a device or emulator.
